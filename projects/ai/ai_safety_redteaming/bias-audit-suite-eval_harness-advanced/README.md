# Bias and Fairness Audit Suite: Eval_Harness

**Domain:** ai | **Subdomain:** ai_safety_redteaming | **Difficulty:** advanced | **Est. build time:** 8-16 hours

---

## Overview

Bias and Fairness Audit Suite built as a eval_harness. Bias audits test whether a model treats demographic groups differently: counterfactual pairs swap group references while holding everything else fixed, and score gaps reveal disparate treatment. Fairness metrics like demographic parity and equalized odds quantify the gaps on seeded tasks. Reports include per-group breakdowns and remediation notes. An evaluation harness that runs test cases against a stub model, measures accuracy and latency, and adds an LLM-as-judge rubric score per case.

## Features

- `build_cases` (`build_cases(seed: int, n: int = 8) -> list`): Seeded arithmetic test cases with expected answers.
- `stub_model` (`stub_model(case: dict, seed: int) -> str`): Deterministic stub model: usually right, sometimes off by one.
- `run_case` (`run_case(case: dict, model_fn, seed: int) -> dict`): Run one case: model output, latency, exact-match correctness.
- `judge_score` (`judge_score(output: str, rubric: dict) -> float`): LLM-as-judge sim: rubric checks over the output text, 0..1.
- `summarize` (`summarize(results: list, judged: list) -> dict`): Aggregate accuracy, avg/p95 latency, and average judge score.
- `run_demo` (`run_demo(seed: int) -> int`): Seeded demo: run cases, judge them, print the table and summary.
- `build_parser` (`build_parser() -> argparse.ArgumentParser`): Build the command-line parser for the demo.
- `main` (`main(argv=None) -> int`): Entry point: seeded eval harness demo.

## How to Run

```
cd projects/ai/ai_safety_redteaming/bias-audit-suite-eval_harness-advanced
python3 src/main.py --help
python3 src/main.py
```
--cases sets the number of seeded test cases; the judge rubric lives in build_rubric().
