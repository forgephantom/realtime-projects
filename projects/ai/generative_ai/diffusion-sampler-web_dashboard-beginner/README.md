# Diffusion Sampling Simulator: Web Dashboard

**Domain:** ai | **Subdomain:** generative_ai | **Difficulty:** beginner | **Est. build time:** 2-4 hours

---

## Overview

Diffusion Sampling Simulator built as a Web dashboard. Diffusion models generate images by reversing a noise process: start from pure noise and iteratively denoise with a learned network, guided by a noise schedule. The sampler discretizes the reverse stochastic differential equation, and step count trades quality against speed. The simulation demonstrates the schedule on 2D toy distributions. Serves a single-page HTML dashboard of topic metrics plus a JSON metrics endpoint.

**Core concept — Diffusion Sampling Simulator:** Diffusion models generate images by reversing a noise process: start from pure noise and iteratively denoise with a learned network, guided by a noise schedule. The sampler discretizes the reverse stochastic differential equation, and step count trades quality against speed. The simulation demonstrates the schedule on 2D toy distributions.

**Why this matters in the real world:** Text-to-image systems use diffusion samplers to render images from prompts.

---

## Features

- **DashboardHandler**: Serves the dashboard HTML page and a JSON metrics endpoint.
- `metric_rows` (`metric_rows(seed, count)`): Generate deterministic synthetic metric rows.
- `render_page` (`render_page(seed, count)`): Render the full dashboard HTML page.
- `start_server` (`start_server(port, seed, count)`): Bind a ThreadingHTTPServer on 127.0.0.1 and serve it in a thread.
- `run_self_test` (`run_self_test(base_url, seed, count)`): Fetch the page and metrics endpoint; print a verification summary.
- `main` (`main()`): Parse args; self-test by default or serve with --serve.

## How It Works

The project is built around Server-side HTML rendering of a metrics table. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n) to render n metric rows. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.
