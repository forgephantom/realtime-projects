# Quiz Question Generator: Command-Line Tool

**Domain:** ai | **Subdomain:** llm_applications | **Difficulty:** advanced | **Est. build time:** 8-16 hours

---

## Overview

Quiz Question Generator built as a Command-line tool. A quiz generator builds multiple-choice questions from study material, writing one correct answer and plausible distractors that target common misconceptions. Difficulty calibration tags each question, and a validation pass rejects questions where distractors are accidentally correct. Answer keys include explanations. A subcommand CLI that generates seeded synthetic topic rows and reports summaries, top-N rows, or filtered rows as tables or JSON.

**Core concept — Quiz Question Generator:** A quiz generator builds multiple-choice questions from study material, writing one correct answer and plausible distractors that target common misconceptions. Difficulty calibration tags each question, and a validation pass rejects questions where distractors are accidentally correct. Answer keys include explanations.

**Why this matters in the real world:** Ed-tech platforms auto-generate practice quizzes from course content.

---

## Features

- `generate_rows` (`generate_rows(seed, count)`): Generate deterministic synthetic topic rows.
- `cmd_summary` (`cmd_summary(rows, args)`): Print per-category counts and value statistics.
- `cmd_top` (`cmd_top(rows, args)`): Print the top-N rows by value.
- `cmd_filter` (`cmd_filter(rows, args)`): Print rows whose value is at least --min-value.
- `main` (`main()`): Parse args and dispatch to the chosen subcommand.

## How It Works

The project is built around Deterministic synthetic rows + subcommand dispatch. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n) to generate rows; O(n log n) for top-N sort. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.

## How to Run

```
cd projects/ai/llm_applications/quiz-question-generator-cli_tool-advanced
python3 src/main.py --help
python3 src/main.py
```
Try `python3 src/main.py top --top-n 3`, `python3 src/main.py filter --min-value 900`, or add --json to any command.

All flags are documented in the CLI itself — run with `--help` to see every option with its default value and meaning.
