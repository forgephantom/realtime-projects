# Semantic Similarity Evaluator: Eval_Harness

**Domain:** ai | **Subdomain:** model_evaluation | **Difficulty:** intermediate | **Est. build time:** 4-8 hours

---

## Overview

Semantic Similarity Evaluator built as a eval_harness. Semantic similarity judges whether two texts mean the same thing, using embedding vectors and cosine similarity instead of word overlap. It rewards good paraphrases that n-gram metrics punish, but it needs a threshold calibrated on labeled pairs and it can miss subtle negation flips. The simulation builds sentence embeddings from seeded random projections to demonstrate the geometry. An evaluation harness that runs test cases against a stub model, measures accuracy and latency, and adds an LLM-as-judge rubric score per case.

**Core concept — Semantic Similarity Evaluator:** Semantic similarity judges whether two texts mean the same thing, using embedding vectors and cosine similarity instead of word overlap. It rewards good paraphrases that n-gram metrics punish, but it needs a threshold calibrated on labeled pairs and it can miss subtle negation flips. The simulation builds sentence embeddings from seeded random projections to demonstrate the geometry.

**Why this matters in the real world:** Semantic answer similarity is the backbone of modern LLM benchmark scoring.

## Features

- `build_cases` (`build_cases(seed: int, n: int = 8) -> list`): Seeded arithmetic test cases with expected answers.
- `stub_model` (`stub_model(case: dict, seed: int) -> str`): Deterministic stub model: usually right, sometimes off by one.
- `run_case` (`run_case(case: dict, model_fn, seed: int) -> dict`): Run one case: model output, latency, exact-match correctness.
- `judge_score` (`judge_score(output: str, rubric: dict) -> float`): LLM-as-judge sim: rubric checks over the output text, 0..1.
- `summarize` (`summarize(results: list, judged: list) -> dict`): Aggregate accuracy, avg/p95 latency, and average judge score.
- `run_demo` (`run_demo(seed: int) -> int`): Seeded demo: run cases, judge them, print the table and summary.
- `build_parser` (`build_parser() -> argparse.ArgumentParser`): Build the command-line parser for the demo.
- `main` (`main(argv=None) -> int`): Entry point: seeded eval harness demo.

## How to Run

