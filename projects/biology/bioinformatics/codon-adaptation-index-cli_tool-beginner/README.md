# Codon Adaptation Index Calculator: Command-Line Tool

**Domain:** biology | **Subdomain:** bioinformatics | **Difficulty:** beginner | **Est. build time:** 2-4 hours

---

## Overview

Codon Adaptation Index Calculator built as a Command-line tool. The codon adaptation index measures how well a gene's codon choices match a reference set of highly expressed genes, computed as the geometric mean of relative adaptiveness values. High CAI predicts high expression. The tool builds the reference table from supplied genes and scores query genes. A subcommand CLI that generates seeded synthetic topic rows and reports summaries, top-N rows, or filtered rows as tables or JSON.

**Core concept — Codon Adaptation Index Calculator:** The codon adaptation index measures how well a gene's codon choices match a reference set of highly expressed genes, computed as the geometric mean of relative adaptiveness values. High CAI predicts high expression. The tool builds the reference table from supplied genes and scores query genes.

**Why this matters in the real world:** CAI guides synthetic-gene design for industrial protein production.

---

## Features

- `generate_rows` (`generate_rows(seed, count)`): Generate deterministic synthetic topic rows.
- `cmd_summary` (`cmd_summary(rows, args)`): Print per-category counts and value statistics.
- `cmd_top` (`cmd_top(rows, args)`): Print the top-N rows by value.
- `cmd_filter` (`cmd_filter(rows, args)`): Print rows whose value is at least --min-value.
- `main` (`main()`): Parse args and dispatch to the chosen subcommand.

## How It Works

The project is built around Deterministic synthetic rows + subcommand dispatch. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n) to generate rows; O(n log n) for top-N sort. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.

## How to Run

```
cd projects/biology/bioinformatics/codon-adaptation-index-cli_tool-beginner
python3 src/main.py --help
python3 src/main.py
```
Try `python3 src/main.py top --top-n 3`, `python3 src/main.py filter --min-value 900`, or add --json to any command.

All flags are documented in the CLI itself — run with `--help` to see every option with its default value and meaning.
