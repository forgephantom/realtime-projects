# Codon Usage Bias Analyzer: Report Generator

**Domain:** biology | **Subdomain:** bioinformatics | **Difficulty:** intermediate | **Est. build time:** 4-8 hours

---

## Overview

Codon Usage Bias Analyzer built as a report generator. Codon usage bias measures how unevenly synonymous codons are used; highly expressed genes prefer codons matching abundant tRNAs. Relative synonymous codon usage (RSCU) normalizes each codon's count by the uniform expectation. The analyzer reports RSCU tables and the effective number of codons. A report generator that builds seeded synthetic data, aggregates it, and writes a Markdown report with summary and per-service tables.

**Core concept — Codon Usage Bias Analyzer:** Codon usage bias measures how unevenly synonymous codons are used; highly expressed genes prefer codons matching abundant tRNAs. Relative synonymous codon usage (RSCU) normalizes each codon's count by the uniform expectation. The analyzer reports RSCU tables and the effective number of codons.

**Why this matters in the real world:** Codon optimization improves recombinant protein expression in biotech manufacturing.

## Features

- `generate_records` (`generate_records(n: int, rng: random.Random) -> list`): Build n seeded synthetic measurement records for the demo.
- `summarize` (`summarize(records: list) -> dict`): Aggregate totals, per-service rollups, error rate, and latency peaks.
- `render_markdown` (`render_markdown(title: str, summary: dict, records: list) -> str`): Render the summary and sample rows as a Markdown document.
- `write_report` (`write_report(path: str, text: str) -> str`): Write the Markdown report, creating parent folders; return the path.
- `run_demo` (`run_demo(seed: int, n_rows: int, out_path: str) -> int`): Generate data, summarize it, write the report, print a summary.
- `build_parser` (`build_parser() -> argparse.ArgumentParser`): Build the command-line parser for the demo.
- `main` (`main(argv=None) -> int`): Parse flags and run the report demo.

Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n) to generate and summarize n records. ## How to Run

```
cd projects/biology/bioinformatics/codon-usage-analyzer-report_generator-intermediate
python3 src/main.py --help
python3 src/main.py
```
--rows sets the record count; --out sets the report path (default ./demo_output/report.md); --title sets the heading.

All flags are documented in the CLI itself — run with `--help` to see every option with its default value and meaning.
