# Founder Effect Simulator: Web Dashboard

**Domain:** biology | **Subdomain:** genetics | **Difficulty:** beginner | **Est. build time:** 2-4 hours

---

## Overview

Founder Effect Simulator built as a Web dashboard. A founder effect occurs when a new population starts from a few individuals, so its allele frequencies are a small random sample of the source, often losing rare alleles entirely. The simulator draws founder samples and tracks diversity loss over subsequent generations. It compares heterozygosity in founders versus source. Serves a single-page HTML dashboard of topic metrics plus a JSON metrics endpoint.

**Core concept — Founder Effect Simulator:** A founder effect occurs when a new population starts from a few individuals, so its allele frequencies are a small random sample of the source, often losing rare alleles entirely. The simulator draws founder samples and tracks diversity loss over subsequent generations. It compares heterozygosity in founders versus source.

**Why this matters in the real world:** Founder effects explain disease alleles in island and isolate populations.

## Features

- **DashboardHandler**: Serves the dashboard HTML page and a JSON metrics endpoint.
- `metric_rows` (`metric_rows(seed, count)`): Generate deterministic synthetic metric rows.
- `render_page` (`render_page(seed, count)`): Render the full dashboard HTML page.
- `start_server` (`start_server(port, seed, count)`): Bind a ThreadingHTTPServer on 127.0.0.1 and serve it in a thread.
- `run_self_test` (`run_self_test(base_url, seed, count)`): Fetch the page and metrics endpoint; print a verification summary.
- `main` (`main()`): Parse args; self-test by default or serve with --serve.

## How It Works

The project is built around Server-side HTML rendering of a metrics table. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n) to render n metric rows. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.
