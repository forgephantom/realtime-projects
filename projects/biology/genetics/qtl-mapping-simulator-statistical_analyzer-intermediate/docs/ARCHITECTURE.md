# Architecture (HLD) — QTL Interval Mapping Simulator: Statistical Analyzer

## Problem & Users

QTL Interval Mapping Simulator built as a Statistical analyzer. QTL mapping crosses divergent lines and tests each genomic position for association with a quantitative trait; LOD-like scores peak near causal loci. The simulator generates a cross with planted QTLs of known effect, runs interval mapping, and reports detected peaks versus truth. It demonstrates the Beavis effect of overestimated small effects. Draws a seeded synthetic sample and reports count, mean, median, stdev, quartiles, and an ASCII histogram.

The intended user is a student or engineer working in biology (genetics) who needs a working, runnable reference for QTL Interval Mapping Simulator — something they can read end to end, run in seconds, and adapt to their own data or experiments.

## Data Flow

```
--seed -> generate_sample (mixture model)
sample -> summarize (sort, moments, percentiles, histogram)
summary -> print_report (table + ASCII histogram)
```

## Storage

In-memory only: the sample and summary exist for the duration of the run and nothing is persisted.

## Scaling & Limits

The sample is sorted in memory, so multi-million-point samples would need a streaming quantile sketch instead.

## Trade-offs

Hand-rolled statistics avoid dependencies but only cover univariate descriptives, not hypothesis tests or modeling.

## Failure Handling

An empty sample cannot occur (n comes from --samples), and a constant sample degrades gracefully to a single non-empty histogram bin.
