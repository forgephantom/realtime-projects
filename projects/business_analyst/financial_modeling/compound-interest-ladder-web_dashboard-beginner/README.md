# Compound Interest Ladder: Web Dashboard

**Domain:** business_analyst | **Subdomain:** financial_modeling | **Difficulty:** beginner | **Est. build time:** 2-4 hours

---

## Overview

Compound Interest Ladder built as a Web dashboard. Compounding grows money on both principal and past interest, which is why early saving dominates late saving. A ladder comparison shows the same monthly deposit at different rates and start years side by side. The visual gap between starting at 25 versus 35 is the most persuasive chart in personal finance. Serves a single-page HTML dashboard of topic metrics plus a JSON metrics endpoint.

**Core concept — Compound Interest Ladder:** Compounding grows money on both principal and past interest, which is why early saving dominates late saving. A ladder comparison shows the same monthly deposit at different rates and start years side by side. The visual gap between starting at 25 versus 35 is the most persuasive chart in personal finance.

**Why this matters in the real world:** Advisors use compounding illustrations to motivate retirement saving.

---

## Features

- **DashboardHandler**: Serves the dashboard HTML page and a JSON metrics endpoint.
- `metric_rows` (`metric_rows(seed, count)`): Generate deterministic synthetic metric rows.
- `render_page` (`render_page(seed, count)`): Render the full dashboard HTML page.
- `start_server` (`start_server(port, seed, count)`): Bind a ThreadingHTTPServer on 127.0.0.1 and serve it in a thread.
- `run_self_test` (`run_self_test(base_url, seed, count)`): Fetch the page and metrics endpoint; print a verification summary.
- `main` (`main()`): Parse args; self-test by default or serve with --serve.

## How It Works

The project is built around Server-side HTML rendering of a metrics table. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n) to render n metric rows. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.

## How to Run

```
cd projects/business_analyst/financial_modeling/compound-interest-ladder-web_dashboard-beginner
python3 src/main.py --help
python3 src/main.py
```
Add --serve to keep the dashboard running instead of self-testing.

All flags are documented in the CLI itself — run with `--help` to see every option with its default value and meaning.
