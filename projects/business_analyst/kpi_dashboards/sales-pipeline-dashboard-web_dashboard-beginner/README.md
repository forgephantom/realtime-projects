# Sales Pipeline Dashboard: Web Dashboard

**Domain:** business_analyst | **Subdomain:** kpi_dashboards | **Difficulty:** beginner | **Est. build time:** 2-4 hours

---

## Overview

Sales Pipeline Dashboard built as a Web dashboard. A pipeline dashboard aggregates every open opportunity by stage, weighting each by its close probability to show expected bookings. Stage conversion rates reveal where deals stall, and aging buckets show which opportunities are quietly dying. It is the earliest warning system a revenue leader has. Serves a single-page HTML dashboard of topic metrics plus a JSON metrics endpoint.

**Core concept — Sales Pipeline Dashboard:** A pipeline dashboard aggregates every open opportunity by stage, weighting each by its close probability to show expected bookings. Stage conversion rates reveal where deals stall, and aging buckets show which opportunities are quietly dying. It is the earliest warning system a revenue leader has.

**Why this matters in the real world:** Sales managers run weekly forecast calls off pipeline dashboards to decide which deals need executive help.

---

## Features

- **DashboardHandler**: Serves the dashboard HTML page and a JSON metrics endpoint.
- `metric_rows` (`metric_rows(seed, count)`): Generate deterministic synthetic metric rows.
- `render_page` (`render_page(seed, count)`): Render the full dashboard HTML page.
- `start_server` (`start_server(port, seed, count)`): Bind a ThreadingHTTPServer on 127.0.0.1 and serve it in a thread.
- `run_self_test` (`run_self_test(base_url, seed, count)`): Fetch the page and metrics endpoint; print a verification summary.
- `main` (`main()`): Parse args; self-test by default or serve with --serve.

## How It Works

The project is built around Server-side HTML rendering of a metrics table. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n) to render n metric rows. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.

## How to Run

```
cd projects/business_analyst/kpi_dashboards/sales-pipeline-dashboard-web_dashboard-beginner
python3 src/main.py --help
python3 src/main.py
```
Add --serve to keep the dashboard running instead of self-testing.

All flags are documented in the CLI itself — run with `--help` to see every option with its default value and meaning.
