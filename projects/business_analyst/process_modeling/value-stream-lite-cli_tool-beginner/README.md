# Value Stream Sketch: Command-Line Tool

**Domain:** business_analyst | **Subdomain:** process_modeling | **Difficulty:** beginner | **Est. build time:** 2-4 hours

---

## Overview

Value Stream Sketch built as a Command-line tool. A lightweight value stream sketch lists the steps from request to delivery with the time each step adds versus the time work waits. The ratio of value time to total lead time is usually shockingly low. Even a rough sketch points improvement effort at the waiting, not the working. A subcommand CLI that generates seeded synthetic topic rows and reports summaries, top-N rows, or filtered rows as tables or JSON.

**Core concept — Value Stream Sketch:** A lightweight value stream sketch lists the steps from request to delivery with the time each step adds versus the time work waits. The ratio of value time to total lead time is usually shockingly low. Even a rough sketch points improvement effort at the waiting, not the working.

**Why this matters in the real world:** Lean teams sketch value streams in kaizen events to target waiting waste.

---

## Features

- `generate_rows` (`generate_rows(seed, count)`): Generate deterministic synthetic topic rows.
- `cmd_summary` (`cmd_summary(rows, args)`): Print per-category counts and value statistics.
- `cmd_top` (`cmd_top(rows, args)`): Print the top-N rows by value.
- `cmd_filter` (`cmd_filter(rows, args)`): Print rows whose value is at least --min-value.
- `main` (`main()`): Parse args and dispatch to the chosen subcommand.

## How It Works

The project is built around Deterministic synthetic rows + subcommand dispatch. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n) to generate rows; O(n log n) for top-N sort. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.

## How to Run

```
cd projects/business_analyst/process_modeling/value-stream-lite-cli_tool-beginner
python3 src/main.py --help
python3 src/main.py
```
Try `python3 src/main.py top --top-n 3`, `python3 src/main.py filter --min-value 900`, or add --json to any command.

All flags are documented in the CLI itself — run with `--help` to see every option with its default value and meaning.
