# Escalation Brief Builder: Report Generator

**Domain:** business_analyst | **Subdomain:** stakeholder_reporting | **Difficulty:** intermediate | **Est. build time:** 4-8 hours

---

## Overview

Escalation Brief Builder built as a report generator. An escalation brief gives a decision-maker everything needed in five minutes: the situation, options with trade-offs, the recommendation, and the cost of delay. Writing it forces clarity about what is actually being asked. The builder assembles the brief from issue data and enforces the one-page limit. A report generator that builds seeded synthetic data, aggregates it, and writes a Markdown report with summary and per-service tables.

**Core concept — Escalation Brief Builder:** An escalation brief gives a decision-maker everything needed in five minutes: the situation, options with trade-offs, the recommendation, and the cost of delay. Writing it forces clarity about what is actually being asked. The builder assembles the brief from issue data and enforces the one-page limit.

**Why this matters in the real world:** Managers escalate with structured briefs so executives can decide fast.

---

## Features

- `generate_records` (`generate_records(n: int, rng: random.Random) -> list`): Build n seeded synthetic measurement records for the demo.
- `summarize` (`summarize(records: list) -> dict`): Aggregate totals, per-service rollups, error rate, and latency peaks.
- `render_markdown` (`render_markdown(title: str, summary: dict, records: list) -> str`): Render the summary and sample rows as a Markdown document.
- `write_report` (`write_report(path: str, text: str) -> str`): Write the Markdown report, creating parent folders; return the path.
- `run_demo` (`run_demo(seed: int, n_rows: int, out_path: str) -> int`): Generate data, summarize it, write the report, print a summary.
- `build_parser` (`build_parser() -> argparse.ArgumentParser`): Build the command-line parser for the demo.
- `main` (`main(argv=None) -> int`): Parse flags and run the report demo.

## How It Works

The project is built around Seeded synthetic data generation, aggregation rollups, Markdown rendering. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n) to generate and summarize n records. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.

## How to Run

```
cd projects/business_analyst/stakeholder_reporting/escalation-brief-builder-report_generator-intermediate
python3 src/main.py --help
python3 src/main.py
```
--rows sets the record count; --out sets the report path (default ./demo_output/report.md); --title sets the heading.

All flags are documented in the CLI itself — run with `--help` to see every option with its default value and meaning.
