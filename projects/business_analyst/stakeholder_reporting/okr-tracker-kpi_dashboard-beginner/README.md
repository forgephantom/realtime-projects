# OKR Progress Tracker: Kpi_Dashboard

**Domain:** business_analyst | **Subdomain:** stakeholder_reporting | **Difficulty:** beginner | **Est. build time:** 2-4 hours

---

## Overview

OKR Progress Tracker built as a kpi_dashboard. OKR tracking scores each key result from 0 to 1 against its target and rolls scores up to objectives. The discipline is separating committed goals from stretch ones so a 0.7 on a stretch is success, not failure. The tracker computes scores, shows confidence trends, and flags at-risk objectives early. A KPI dashboard that computes growth rate, churn, CAC, and LTV from seeded synthetic business data and renders an ASCII dashboard with sparklines.

**Core concept — OKR Progress Tracker:** OKR tracking scores each key result from 0 to 1 against its target and rolls scores up to objectives. The discipline is separating committed goals from stretch ones so a 0.7 on a stretch is success, not failure. The tracker computes scores, shows confidence trends, and flags at-risk objectives early.

**Why this matters in the real world:** Companies run quarterly OKR reviews to align teams on outcomes.

## Features

- `generate_business_data` (`generate_business_data(seed: int, months: int = 12) -> dict`): Seeded 12-month synthetic series: revenue, users, adds, churn, spend.
- `compute_kpis` (`compute_kpis(data: dict) -> dict`): Growth rate, churn rate, CAC, and LTV from the series.
- `sparkline` (`sparkline(values: list) -> str`): Map a numeric series to unicode block sparkline characters.
- `render_dashboard` (`render_dashboard(data: dict, kpis: dict) -> str`): Format the KPI values and sparklines as an ASCII dashboard.
- `run_demo` (`run_demo(seed: int) -> int`): Seeded demo: generate data, compute KPIs, print the dashboard.
- `build_parser` (`build_parser() -> argparse.ArgumentParser`): Build the command-line parser for the demo.
- `main` (`main(argv=None) -> int`): Entry point: seeded KPI dashboard demo.

## How It Works

The project is built around Seeded geometric-growth business series; KPIs from period ratios: growth, churn, CAC, and LTV from ARPU over churn.. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(M) over M months of synthetic data; all KPI math is O(1) on aggregates.. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.

## How to Run

```
cd projects/business_analyst/stakeholder_reporting/okr-tracker-kpi_dashboard-beginner
python3 src/main.py --help
python3 src/main.py
```
--months sets the synthetic history length; values are seeded and reproducible.

All flags are documented in the CLI itself — run with `--help` to see every option with its default value and meaning.
