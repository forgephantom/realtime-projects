# Air Quality Index Calculator: Monitoring Agent

**Domain:** chemistry | **Subdomain:** chemistry | **Difficulty:** advanced | **Est. build time:** 8-16 hours

---

## Overview

Air Quality Index Calculator built as a Monitoring agent. The air quality index converts pollutant concentrations into a single 0 to 500 scale using breakpoint tables, with the worst pollutant setting the overall index. The calculator ingests sensor readings and reports the index with its health category. Samples synthetic topic metrics for N cycles, evaluates each reading against thresholds, prints readings and alerts.

**Core concept — Air Quality Index Calculator:** The air quality index converts pollutant concentrations into a single 0 to 500 scale using breakpoint tables, with the worst pollutant setting the overall index. The calculator ingests sensor readings and reports the index with its health category.

**Why this matters in the real world:** Environmental agencies publish daily air quality indices from monitoring networks.

---

## Features

- **Monitor**: Samples metrics, evaluates thresholds, and collects alerts.
- `read_metrics` (`read_metrics(rng, cycle)`): Sample one synthetic topic metric reading.
- `check_thresholds` (`check_thresholds(reading, thresholds)`): Return a list of alert strings for readings over threshold.
- `Monitor.run` (`Monitor.run(self, cycles, interval)`): Sample `cycles` readings, print them, return alert count.
- `main` (`main()`): Parse args and run the monitor.

## How It Works

The project is built around Periodic sampling with static threshold evaluation. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(cycles) total; O(1) per sample. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.
