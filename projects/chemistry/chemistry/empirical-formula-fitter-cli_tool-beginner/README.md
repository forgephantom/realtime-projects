# Empirical Formula Fitter: Command-Line Tool

**Domain:** chemistry | **Subdomain:** chemistry | **Difficulty:** beginner | **Est. build time:** 2-4 hours

---

## Overview

Empirical Formula Fitter built as a Command-line tool. Combustion analysis gives the mass of each element in a compound, and dividing by atomic weights then by the smallest value yields the simplest whole-number ratio. The fitter converts elemental analysis data into empirical formulas. A subcommand CLI that generates seeded synthetic topic rows and reports summaries, top-N rows, or filtered rows as tables or JSON.

**Core concept — Empirical Formula Fitter:** Combustion analysis gives the mass of each element in a compound, and dividing by atomic weights then by the smallest value yields the simplest whole-number ratio. The fitter converts elemental analysis data into empirical formulas.

**Why this matters in the real world:** Forensic labs identify unknown organics from elemental analysis.

---

## Features

- `generate_rows` (`generate_rows(seed, count)`): Generate deterministic synthetic topic rows.
- `cmd_summary` (`cmd_summary(rows, args)`): Print per-category counts and value statistics.
- `cmd_top` (`cmd_top(rows, args)`): Print the top-N rows by value.
- `cmd_filter` (`cmd_filter(rows, args)`): Print rows whose value is at least --min-value.
- `main` (`main()`): Parse args and dispatch to the chosen subcommand.

## How It Works

The project is built around Deterministic synthetic rows + subcommand dispatch. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n) to generate rows; O(n log n) for top-N sort. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.

## How to Run

```
cd projects/chemistry/chemistry/empirical-formula-fitter-cli_tool-beginner
python3 src/main.py --help
python3 src/main.py
```
Try `python3 src/main.py top --top-n 3`, `python3 src/main.py filter --min-value 900`, or add --json to any command.

All flags are documented in the CLI itself — run with `--help` to see every option with its default value and meaning.
