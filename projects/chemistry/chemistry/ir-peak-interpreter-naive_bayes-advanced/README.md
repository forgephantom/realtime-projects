# IR Peak Interpreter: Naive Bayes Classifier

**Domain:** chemistry | **Subdomain:** chemistry | **Difficulty:** advanced | **Est. build time:** 8-16 hours

---

## Overview

IR Peak Interpreter built as a Naive Bayes classifier. Infrared absorption peaks correspond to vibrating bonds, so a broad band near 3300 reciprocal centimeters suggests O-H or N-H while a sharp peak near 1700 suggests a carbonyl. The interpreter classifies functional groups from peak lists using learned patterns. Trains a Gaussian Naive Bayes classifier on seeded synthetic features and reports priors, accuracy, and the confusion matrix.

**Core concept — IR Peak Interpreter:** Infrared absorption peaks correspond to vibrating bonds, so a broad band near 3300 reciprocal centimeters suggests O-H or N-H while a sharp peak near 1700 suggests a carbonyl. The interpreter classifies functional groups from peak lists using learned patterns.

**Why this matters in the real world:** Organic chemists confirm synthesized structures by interpreting IR spectra.

## Features

- **GaussianNB**: Naive Bayes classifier with Gaussian feature likelihoods.
- `generate_dataset` (`generate_dataset(seed, n)`): Generate 2-feature topic vectors with binary labels.
- `split_dataset` (`split_dataset(X, y, train_frac, seed)`): Shuffle and split into (X_train, y_train, X_test, y_test).
- `GaussianNB.fit` (`GaussianNB.fit(self, X, y)`): Estimate per-class priors and per-feature (mean, var).
- `GaussianNB.predict` (`GaussianNB.predict(self, X)`): Return the most likely class for each feature vector.
- `main` (`main()`): Parse args, train, and print accuracy and confusion matrix.

## How It Works

The project is built around Gaussian Naive Bayes with log-space scoring. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n*d) to fit n samples with d features; O(c*d) per prediction. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.
