# Reaction Order Determiner: Linear Regression

**Domain:** chemistry | **Subdomain:** chemistry | **Difficulty:** advanced | **Est. build time:** 8-16 hours

---

## Overview

Reaction Order Determiner built as a Linear regression. The reaction order reveals how the rate depends on each reactant's concentration, found by comparing initial rates across experiments. A log-log plot of rate against concentration has a slope equal to the order in that reactant. Fits y = slope*x + intercept by closed-form least squares on seeded synthetic data and reports coefficients, R^2, and predictions.

**Core concept — Reaction Order Determiner:** The reaction order reveals how the rate depends on each reactant's concentration, found by comparing initial rates across experiments. A log-log plot of rate against concentration has a slope equal to the order in that reactant.

**Why this matters in the real world:** Kineticists map out rate laws to design reactors that run at optimal concentrations.

---

## Features

- `generate_data` (`generate_data(seed, n, slope, intercept, noise)`): Generate noisy (x, y) pairs around the true line.
- `fit_least_squares` (`fit_least_squares(xs, ys)`): Closed-form least-squares fit; returns (slope, intercept).
- `r_squared` (`r_squared(xs, ys, slope, intercept)`): Coefficient of determination for the fitted line.
- `main` (`main()`): Parse args, fit, and print coefficients and predictions.

## How It Works

The project is built around Ordinary least squares, closed-form normal equations. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n) to fit n points. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.
