# Lifecycle Policy Engine: Statistical Analyzer

**Domain:** computer_science | **Subdomain:** cloud_computing | **Difficulty:** beginner | **Est. build time:** 2-4 hours

---

## Overview

Lifecycle Policy Engine built as a Statistical analyzer. Storage lifecycle policies move aging data to cheaper tiers and eventually delete it. The engine applies rules to object inventories, projecting cost savings and flagging premature transitions. Tiering automation with guardrails. Draws a seeded synthetic sample and reports count, mean, median, stdev, quartiles, and an ASCII histogram.

**Core concept — Lifecycle Policy Engine:** Storage lifecycle policies move aging data to cheaper tiers and eventually delete it. The engine applies rules to object inventories, projecting cost savings and flagging premature transitions. Tiering automation with guardrails.

**Why this matters in the real world:** Used managing storage costs.

---

## Features

- `generate_sample` (`generate_sample(seed, n)`): Draw synthetic topic measurements (mixture model).
- `percentile` (`percentile(sorted_vals, q)`): Linear-interpolation percentile of a pre-sorted list.
- `summarize` (`summarize(values, bins)`): Compute a full descriptive-statistics summary.
- `print_report` (`print_report(summary)`): Print the summary table and ASCII histogram.
- `main` (`main()`): Parse args and print the report.

## How It Works

The project is built around Descriptive statistics with linear-interpolation percentiles. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n log n) for the sort; O(n) for the histogram pass. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.
