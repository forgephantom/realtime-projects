# Savings Plan Analyzer: Linear Regression

**Domain:** computer_science | **Subdomain:** cloud_computing | **Difficulty:** intermediate | **Est. build time:** 4-8 hours

---

## Overview

Savings Plan Analyzer built as a Linear regression. Savings plans discount compute in exchange for hourly commitments, with utilization deciding the payoff. The analyzer models commitment levels against usage variability. It optimizes the commitment portfolio. Fits y = slope*x + intercept by closed-form least squares on seeded synthetic data and reports coefficients, R^2, and predictions.

**Core concept — Savings Plan Analyzer:** Savings plans discount compute in exchange for hourly commitments, with utilization deciding the payoff. The analyzer models commitment levels against usage variability. It optimizes the commitment portfolio.

**Why this matters in the real world:** Used by FinOps buying savings plans.

---

## Features

- `generate_data` (`generate_data(seed, n, slope, intercept, noise)`): Generate noisy (x, y) pairs around the true line.
- `fit_least_squares` (`fit_least_squares(xs, ys)`): Closed-form least-squares fit; returns (slope, intercept).
- `r_squared` (`r_squared(xs, ys, slope, intercept)`): Coefficient of determination for the fitted line.
- `main` (`main()`): Parse args, fit, and print coefficients and predictions.

## How It Works

The project is built around Ordinary least squares, closed-form normal equations. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n) to fit n points. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.
