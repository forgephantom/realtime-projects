# Architecture (HLD) — OAuth Scope Analyzer: Statistical Analyzer

## Problem & Users

OAuth Scope Analyzer built as a Statistical analyzer. OAuth scopes define what a third-party app may do on a user's behalf, and over-broad grants turn a compromised app into a full account takeover. The analyzer inventories granted scopes per application, flags sensitive combinations like read plus delete, and recommends least-privilege reductions. It also spots apps that have not been used in months. Draws a seeded synthetic sample and reports count, mean, median, stdev, quartiles, and an ASCII histogram.

The intended user is a student or engineer working in computer_science (cybersecurity) who needs a working, runnable reference for OAuth Scope Analyzer — something they can read end to end, run in seconds, and adapt to their own data or experiments.

## Data Flow

```
--seed -> generate_sample (mixture model)
sample -> summarize (sort, moments, percentiles, histogram)
summary -> print_report (table + ASCII histogram)
```

## Storage

In-memory only: the sample and summary exist for the duration of the run and nothing is persisted.

## Scaling & Limits

The sample is sorted in memory, so multi-million-point samples would need a streaming quantile sketch instead.

## Trade-offs

Hand-rolled statistics avoid dependencies but only cover univariate descriptives, not hypothesis tests or modeling.

## Failure Handling

An empty sample cannot occur (n comes from --samples), and a constant sample degrades gracefully to a single non-empty histogram bin.
