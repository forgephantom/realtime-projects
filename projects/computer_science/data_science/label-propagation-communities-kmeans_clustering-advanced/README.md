# Label Propagation Communities: K-Means Clustering

**Domain:** computer_science | **Subdomain:** data_science | **Difficulty:** advanced | **Est. build time:** 8-16 hours

---

## Overview

Label Propagation Communities built as a K-means clustering. Communities are dense subgraphs: label propagation lets nodes adopt their neighbors' most common label iteratively until convergence, finding communities without pre-set counts. It is fast and simple; oscillation handling (async updates) stabilizes it. Modularity scores the result. Runs Lloyd's k-means on seeded 2-D synthetic points and prints final centroids, cluster sizes, and inertia.

**Core concept — Label Propagation Communities:** Communities are dense subgraphs: label propagation lets nodes adopt their neighbors' most common label iteratively until convergence, finding communities without pre-set counts. It is fast and simple; oscillation handling (async updates) stabilizes it. Modularity scores the result.

**Why this matters in the real world:** Social community detection and fraud-ring discovery use propagation methods.

---

## Features

- `generate_points` (`generate_points(seed, n, k)`): Generate 2-D points around k random topic centers.
- `assign` (`assign(points, centroids)`): Assign each point to its nearest centroid; return label list.
- `recompute` (`recompute(points, labels, k, centroids)`): Recompute centroids as cluster means; keep old center if empty.
- `inertia` (`inertia(points, labels, centroids)`): Sum of squared distances of points to their assigned centroid.
- `kmeans` (`kmeans(points, k, iterations, seed)`): Run Lloyd's algorithm; return (centroids, labels).
- `main` (`main()`): Parse args, cluster, and print centroids and inertia.

## How It Works

The project is built around Lloyd's k-means: assign, recompute, repeat until convergence. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n*k*i) for n points, k clusters, i iterations. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.
