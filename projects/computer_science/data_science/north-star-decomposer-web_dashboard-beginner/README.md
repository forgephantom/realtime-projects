# North Star Metric Decomposer: Web Dashboard

**Domain:** computer_science | **Subdomain:** data_science | **Difficulty:** beginner | **Est. build time:** 2-4 hours

---

## Overview

North Star Metric Decomposer built as a Web dashboard. A north-star metric decomposes into inputs: the decomposer breaks it multiplicatively (users x activation x frequency x monetization) and attributes changes to components. Waterfall charts show which lever moved. It turns one number into an operating plan. Serves a single-page HTML dashboard of topic metrics plus a JSON metrics endpoint.

**Core concept — North Star Metric Decomposer:** A north-star metric decomposes into inputs: the decomposer breaks it multiplicatively (users x activation x frequency x monetization) and attributes changes to components. Waterfall charts show which lever moved. It turns one number into an operating plan.

**Why this matters in the real world:** Product leadership (Amplitude's north-star framework) decomposes the headline metric.

---

## Features

- **DashboardHandler**: Serves the dashboard HTML page and a JSON metrics endpoint.
- `metric_rows` (`metric_rows(seed, count)`): Generate deterministic synthetic metric rows.
- `render_page` (`render_page(seed, count)`): Render the full dashboard HTML page.
- `start_server` (`start_server(port, seed, count)`): Bind a ThreadingHTTPServer on 127.0.0.1 and serve it in a thread.
- `run_self_test` (`run_self_test(base_url, seed, count)`): Fetch the page and metrics endpoint; print a verification summary.
- `main` (`main()`): Parse args; self-test by default or serve with --serve.

## How It Works

The project is built around Server-side HTML rendering of a metrics table. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n) to render n metric rows. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.

## How to Run

```
cd projects/computer_science/data_science/north-star-decomposer-web_dashboard-beginner
python3 src/main.py --help
python3 src/main.py
```
Add --serve to keep the dashboard running instead of self-testing.

All flags are documented in the CLI itself — run with `--help` to see every option with its default value and meaning.
