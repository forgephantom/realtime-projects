# Resource Rightsizer: Monitoring Agent

**Domain:** computer_science | **Subdomain:** devops_sre | **Difficulty:** beginner | **Est. build time:** 2-4 hours

---

## Overview

Resource Rightsizer built as a Monitoring agent. Most instances run at a fraction of their provisioned CPU and memory, wasting money around the clock. The rightsizer analyzes utilization percentiles over weeks and recommends smaller shapes that still cover peaks with headroom. It quantifies the savings per recommendation. Samples synthetic topic metrics for N cycles, evaluates each reading against thresholds, prints readings and alerts.

**Core concept — Resource Rightsizer:** Most instances run at a fraction of their provisioned CPU and memory, wasting money around the clock. The rightsizer analyzes utilization percentiles over weeks and recommends smaller shapes that still cover peaks with headroom. It quantifies the savings per recommendation.

**Why this matters in the real world:** Used by FinOps teams cutting cloud waste.

---

## Features

- **Monitor**: Samples metrics, evaluates thresholds, and collects alerts.
- `read_metrics` (`read_metrics(rng, cycle)`): Sample one synthetic topic metric reading.
- `check_thresholds` (`check_thresholds(reading, thresholds)`): Return a list of alert strings for readings over threshold.
- `Monitor.run` (`Monitor.run(self, cycles, interval)`): Sample `cycles` readings, print them, return alert count.
- `main` (`main()`): Parse args and run the monitor.

## How It Works

The project is built around Periodic sampling with static threshold evaluation. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(cycles) total; O(1) per sample. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.
