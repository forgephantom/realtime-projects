# Skill Tree: Simulation (Logistic Growth)

**Domain:** computer_science | **Subdomain:** game_development | **Difficulty:** intermediate | **Est. build time:** 4-8 hours

---

## Overview

Skill Tree built as a Simulation (logistic growth). Skill trees gate abilities behind prerequisites with point budgets. The system validates allocations and computes build stats. Choices matter. Euler-integrates logistic growth dP/dt = r*P*(1-P/K) and prints the trajectory table with summary statistics.

**Core concept — Skill Tree:** Skill trees gate abilities behind prerequisites with point budgets. The system validates allocations and computes build stats. Choices matter.

**Why this matters in the real world:** Used in RPGs.

---

## Features

- `simulate` (`simulate(params, steps, dt)`): Euler-integrate logistic growth; return [(t, value)] rows.
- `print_trajectory` (`print_trajectory(rows, every)`): Print every Nth trajectory row plus the final state.
- `main` (`main()`): Parse args, simulate, and print the trajectory and summary.
