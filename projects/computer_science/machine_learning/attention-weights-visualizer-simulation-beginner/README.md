# Attention Weights Visualizer: Simulation (Logistic Growth)

**Domain:** computer_science | **Subdomain:** machine_learning | **Difficulty:** beginner | **Est. build time:** 2-4 hours

---

## Overview

Attention Weights Visualizer built as a Simulation (logistic growth). Attention computes weighted averages of values by query-key similarity: the visualizer shows the weight matrix as a heatmap over a tiny translation-like task, revealing which inputs each output attends to. It makes the 'attention is all you need' claim concrete and inspectable. Euler-integrates logistic growth dP/dt = r*P*(1-P/K) and prints the trajectory table with summary statistics.

**Core concept — Attention Weights Visualizer:** Attention computes weighted averages of values by query-key similarity: the visualizer shows the weight matrix as a heatmap over a tiny translation-like task, revealing which inputs each output attends to. It makes the 'attention is all you need' claim concrete and inspectable.

**Why this matters in the real world:** Model interpretability for transformers starts with attention visualization.

---

## Features

- `simulate` (`simulate(params, steps, dt)`): Euler-integrate logistic growth; return [(t, value)] rows.
- `print_trajectory` (`print_trajectory(rows, every)`): Print every Nth trajectory row plus the final state.
- `main` (`main()`): Parse args, simulate, and print the trajectory and summary.
