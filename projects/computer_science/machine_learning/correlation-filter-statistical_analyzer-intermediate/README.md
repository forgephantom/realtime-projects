# Correlation Filter: Statistical Analyzer

**Domain:** computer_science | **Subdomain:** machine_learning | **Difficulty:** intermediate | **Est. build time:** 4-8 hours

---

## Overview

Correlation Filter built as a Statistical analyzer. Highly correlated feature pairs are redundant: the filter finds pairs above a threshold and drops the one less correlated with the target. It is the cheapest multicollinearity fix and a standard first cleaning step. The threshold trades information loss against simplicity. Draws a seeded synthetic sample and reports count, mean, median, stdev, quartiles, and an ASCII histogram.

**Core concept — Correlation Filter:** Highly correlated feature pairs are redundant: the filter finds pairs above a threshold and drops the one less correlated with the target. It is the cheapest multicollinearity fix and a standard first cleaning step. The threshold trades information loss against simplicity.

**Why this matters in the real world:** First-pass feature cleaning in finance and sensor modeling.

---

## Features

- `generate_sample` (`generate_sample(seed, n)`): Draw synthetic topic measurements (mixture model).
- `percentile` (`percentile(sorted_vals, q)`): Linear-interpolation percentile of a pre-sorted list.
- `summarize` (`summarize(values, bins)`): Compute a full descriptive-statistics summary.
- `print_report` (`print_report(summary)`): Print the summary table and ASCII histogram.
- `main` (`main()`): Parse args and print the report.
