# Early Stopping Monitor: Task Scheduler

**Domain:** computer_science | **Subdomain:** machine_learning | **Difficulty:** beginner | **Est. build time:** 2-4 hours

---

## Overview

Early Stopping Monitor built as a Task scheduler. Early stopping halts training when validation loss stops improving, with patience tolerating noisy plateaus and restore-best-weights keeping the peak model. It is free regularization that also saves compute. The demo shows how patience choice affects the final model. Registers interval jobs on a heap scheduler, runs them for a fixed demo duration, and prints the execution log.

**Core concept — Early Stopping Monitor:** Early stopping halts training when validation loss stops improving, with patience tolerating noisy plateaus and restore-best-weights keeping the peak model. It is free regularization that also saves compute. The demo shows how patience choice affects the final model.

**Why this matters in the real world:** Neural network training universally uses early stopping to prevent overfitting.

---

## Features

- **Scheduler**: Minimal interval scheduler driven by a heap of next-run times.
- `make_demo_job` (`make_demo_job(tag)`): Build a demo job function that counts its own executions.
- `Scheduler.add_job` (`Scheduler.add_job(self, name, interval, func)`): Register `func` to run every `interval` seconds under `name`.
- `Scheduler.run` (`Scheduler.run(self, duration)`): Run scheduled jobs for `duration` seconds; return the log.
- `main` (`main()`): Parse args, register demo jobs, run, and print the log.

## How It Works

The project is built around Heap-ordered next-run-time scheduling loop. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(log j) per execution for j jobs. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.
