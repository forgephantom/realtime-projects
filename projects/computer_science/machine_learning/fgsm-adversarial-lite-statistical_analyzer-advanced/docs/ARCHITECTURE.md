# Architecture (HLD) — FGSM Adversarial Examples (Lite): Statistical Analyzer

## Problem & Users

FGSM Adversarial Examples (Lite) built as a Statistical analyzer. The fast gradient sign method crafts adversarial examples by nudging inputs along the gradient sign within an epsilon ball: imperceptible changes flip predictions. The lite demo attacks a tiny linear/logistic model to show the mechanism plainly. Adversarial training is the standard defense. Draws a seeded synthetic sample and reports count, mean, median, stdev, quartiles, and an ASCII histogram.

The intended user is a student or engineer working in computer_science (machine_learning) who needs a working, runnable reference for FGSM Adversarial Examples (Lite) — something they can read end to end, run in seconds, and adapt to their own data or experiments.

## Data Flow

```
--seed -> generate_sample (mixture model)
sample -> summarize (sort, moments, percentiles, histogram)
summary -> print_report (table + ASCII histogram)
```

## Storage

In-memory only: the sample and summary exist for the duration of the run and nothing is persisted.

## Scaling & Limits

The sample is sorted in memory, so multi-million-point samples would need a streaming quantile sketch instead.

## Trade-offs

Hand-rolled statistics avoid dependencies but only cover univariate descriptives, not hypothesis tests or modeling.

## Failure Handling

An empty sample cannot occur (n comes from --samples), and a constant sample degrades gracefully to a single non-empty histogram bin.
