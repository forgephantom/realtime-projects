# Polynomial Feature Expansion: Web Dashboard

**Domain:** computer_science | **Subdomain:** machine_learning | **Difficulty:** beginner | **Est. build time:** 2-4 hours

---

## Overview

Polynomial Feature Expansion built as a Web dashboard. Linear models can fit curves if you first expand features into polynomial terms: x becomes [x, x^2, x^3], and OLS fits the rest. Degree controls flexibility, and high degrees overfit wildly without regularization. It is the simplest way to see the bias-variance trade-off in action. Serves a single-page HTML dashboard of topic metrics plus a JSON metrics endpoint.

**Core concept — Polynomial Feature Expansion:** Linear models can fit curves if you first expand features into polynomial terms: x becomes [x, x^2, x^3], and OLS fits the rest. Degree controls flexibility, and high degrees overfit wildly without regularization. It is the simplest way to see the bias-variance trade-off in action.

**Why this matters in the real world:** Introductory ML courses and quick nonlinear baselines use polynomial expansion before kernels.

---

## Features

- **DashboardHandler**: Serves the dashboard HTML page and a JSON metrics endpoint.
- `metric_rows` (`metric_rows(seed, count)`): Generate deterministic synthetic metric rows.
- `render_page` (`render_page(seed, count)`): Render the full dashboard HTML page.
- `start_server` (`start_server(port, seed, count)`): Bind a ThreadingHTTPServer on 127.0.0.1 and serve it in a thread.
- `run_self_test` (`run_self_test(base_url, seed, count)`): Fetch the page and metrics endpoint; print a verification summary.
- `main` (`main()`): Parse args; self-test by default or serve with --serve.

## How It Works

The project is built around Server-side HTML rendering of a metrics table. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n) to render n metric rows. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.
