# Architecture (HLD) — Shapley Value Demo: Statistical Analyzer

## Problem & Users

Shapley Value Demo built as a Statistical analyzer. Shapley values fairly attribute a prediction among features using cooperative game theory: each feature's marginal contribution averaged over all orderings. Exact computation is exponential, so the demo runs small-n exact and sampling approximations. It is the principled answer to 'which feature mattered'. Draws a seeded synthetic sample and reports count, mean, median, stdev, quartiles, and an ASCII histogram.

The intended user is a student or engineer working in computer_science (machine_learning) who needs a working, runnable reference for Shapley Value Demo — something they can read end to end, run in seconds, and adapt to their own data or experiments.

## Data Flow

```
--seed -> generate_sample (mixture model)
sample -> summarize (sort, moments, percentiles, histogram)
summary -> print_report (table + ASCII histogram)
```

## Storage

In-memory only: the sample and summary exist for the duration of the run and nothing is persisted.

## Scaling & Limits

The sample is sorted in memory, so multi-million-point samples would need a streaming quantile sketch instead.

## Trade-offs

Hand-rolled statistics avoid dependencies but only cover univariate descriptives, not hypothesis tests or modeling.

## Failure Handling

An empty sample cannot occur (n comes from --samples), and a constant sample degrades gracefully to a single non-empty histogram bin.
