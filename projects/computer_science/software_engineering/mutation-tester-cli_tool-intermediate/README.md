# Mutation Tester: Command-Line Tool

**Domain:** computer_science | **Subdomain:** software_engineering | **Difficulty:** intermediate | **Est. build time:** 4-8 hours

---

## Overview

Mutation Tester built as a Command-line tool. Mutation testing judges test quality by breaking the code: mutants (changed operators, removed conditions) should be killed by failing tests; surviving mutants reveal weak tests. The mutation score is the honest coverage metric. It is expensive, so the lite version mutates selectively. A subcommand CLI that generates seeded synthetic topic rows and reports summaries, top-N rows, or filtered rows as tables or JSON.

**Core concept — Mutation Tester:** Mutation testing judges test quality by breaking the code: mutants (changed operators, removed conditions) should be killed by failing tests; surviving mutants reveal weak tests. The mutation score is the honest coverage metric. It is expensive, so the lite version mutates selectively.

**Why this matters in the real world:** PIT (Java), Stryker (JS) measure test-suite strength with mutation scores.

---

## Features

- `generate_rows` (`generate_rows(seed, count)`): Generate deterministic synthetic topic rows.
- `cmd_summary` (`cmd_summary(rows, args)`): Print per-category counts and value statistics.
- `cmd_top` (`cmd_top(rows, args)`): Print the top-N rows by value.
- `cmd_filter` (`cmd_filter(rows, args)`): Print rows whose value is at least --min-value.
- `main` (`main()`): Parse args and dispatch to the chosen subcommand.

## How It Works

The project is built around Deterministic synthetic rows + subcommand dispatch. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n) to generate rows; O(n log n) for top-N sort. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.

## How to Run

```
cd projects/computer_science/software_engineering/mutation-tester-cli_tool-intermediate
python3 src/main.py --help
python3 src/main.py
```
Try `python3 src/main.py top --top-n 3`, `python3 src/main.py filter --min-value 900`, or add --json to any command.

All flags are documented in the CLI itself — run with `--help` to see every option with its default value and meaning.
