**Domain:** computer_science | **Subdomain:** software_engineering | **Difficulty:** beginner | **Est. build time:** 2-4 hours

## Overview

Prototype (Cloner) built as a Command-line tool. Prototype creates objects by cloning a template instead of constructing from scratch: useful when setup is expensive (database fixtures, document templates). Deep vs shallow copy semantics decide whether nested state is shared. Registries of named prototypes act as template libraries. A subcommand CLI that generates seeded synthetic topic rows and reports summaries, top-N rows, or filtered rows as tables or JSON.

**Core concept — Prototype (Cloner):** Prototype creates objects by cloning a template instead of constructing from scratch: useful when setup is expensive (database fixtures, document templates). Deep vs shallow copy semantics decide whether nested state is shared. Registries of named prototypes act as template libraries.

**Why this matters in the real world:** Game entity spawning, document templates, and test-fixture factories clone prototypes.

---

## Features

- `generate_rows` (`generate_rows(seed, count)`): Generate deterministic synthetic topic rows.
- `cmd_summary` (`cmd_summary(rows, args)`): Print per-category counts and value statistics.
- `cmd_top` (`cmd_top(rows, args)`): Print the top-N rows by value.
- `cmd_filter` (`cmd_filter(rows, args)`): Print rows whose value is at least --min-value.
- `main` (`main()`): Parse args and dispatch to the chosen subcommand.

## How It Works

The project is built around Deterministic synthetic rows + subcommand dispatch. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n) to generate rows; O(n log n) for top-N sort. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.

## How to Run

```
cd projects/computer_science/software_engineering/prototype-cloner-cli_tool-beginner
python3 src/main.py --help
python3 src/main.py
```
Try `python3 src/main.py top --top-n 3`, `python3 src/main.py filter --min-value 900`, or add --json to any command.

All flags are documented in the CLI itself — run with `--help` to see every option with its default value and meaning.
