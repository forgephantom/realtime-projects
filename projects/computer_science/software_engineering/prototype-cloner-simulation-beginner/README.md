# Prototype (Cloner): Simulation (Logistic Growth)

**Domain:** computer_science | **Subdomain:** software_engineering | **Difficulty:** beginner | **Est. build time:** 2-4 hours

---

## Overview

Prototype (Cloner) built as a Simulation (logistic growth). Prototype creates objects by cloning a template instead of constructing from scratch: useful when setup is expensive (database fixtures, document templates). Deep vs shallow copy semantics decide whether nested state is shared. Registries of named prototypes act as template libraries. Euler-integrates logistic growth dP/dt = r*P*(1-P/K) and prints the trajectory table with summary statistics.

**Core concept — Prototype (Cloner):** Prototype creates objects by cloning a template instead of constructing from scratch: useful when setup is expensive (database fixtures, document templates). Deep vs shallow copy semantics decide whether nested state is shared. Registries of named prototypes act as template libraries.

**Why this matters in the real world:** Game entity spawning, document templates, and test-fixture factories clone prototypes.

---

## Features

- `simulate` (`simulate(params, steps, dt)`): Euler-integrate logistic growth; return [(t, value)] rows.
- `print_trajectory` (`print_trajectory(rows, every)`): Print every Nth trajectory row plus the final state.
- `main` (`main()`): Parse args, simulate, and print the trajectory and summary.
