# Audio VU Meter Simulator: Simulation (Logistic Growth)

**Domain:** electronics_engineering | **Subdomain:** electronics_engineering | **Difficulty:** intermediate | **Est. build time:** 4-8 hours

---

## Overview

Audio VU Meter Simulator built as a Simulation (logistic growth). A VU meter shows audio level with ballistic smoothing that mimics the old analog needle, rising fast and falling slowly. The simulator processes audio amplitude envelopes and renders the needle position in ASCII. Euler-integrates logistic growth dP/dt = r*P*(1-P/K) and prints the trajectory table with summary statistics.

**Core concept — Audio VU Meter Simulator:** A VU meter shows audio level with ballistic smoothing that mimics the old analog needle, rising fast and falling slowly. The simulator processes audio amplitude envelopes and renders the needle position in ASCII.

**Why this matters in the real world:** Mixing consoles and broadcast chains monitor levels with VU-style metering.

---

## Features

- `simulate` (`simulate(params, steps, dt)`): Euler-integrate logistic growth; return [(t, value)] rows.
- `print_trajectory` (`print_trajectory(rows, every)`): Print every Nth trajectory row plus the final state.
- `main` (`main()`): Parse args, simulate, and print the trajectory and summary.
