# Hall Sensor Mapper: Simulation (Logistic Growth)

**Domain:** electronics_engineering | **Subdomain:** electronics_engineering | **Difficulty:** beginner | **Est. build time:** 2-4 hours

---

## Overview

Hall Sensor Mapper built as a Simulation (logistic growth). A Hall element outputs a voltage proportional to the magnetic field through it, so mapping the field of a magnet array lets a designer place sensors where the gradient is steepest. Euler-integrates logistic growth dP/dt = r*P*(1-P/K) and prints the trajectory table with summary statistics.

**Core concept — Hall Sensor Mapper:** A Hall element outputs a voltage proportional to the magnetic field through it, so mapping the field of a magnet array lets a designer place sensors where the gradient is steepest.

**Why this matters in the real world:** Used in BLDC commutation and position sensing to place Hall latches for reliable switching.

---

## Features

- `simulate` (`simulate(params, steps, dt)`): Euler-integrate logistic growth; return [(t, value)] rows.
- `print_trajectory` (`print_trajectory(rows, every)`): Print every Nth trajectory row plus the final state.
- `main` (`main()`): Parse args, simulate, and print the trajectory and summary.
