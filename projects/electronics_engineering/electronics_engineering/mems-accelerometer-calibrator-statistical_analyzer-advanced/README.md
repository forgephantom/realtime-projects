# MEMS Accelerometer Calibrator: Statistical Analyzer

**Domain:** electronics_engineering | **Subdomain:** electronics_engineering | **Difficulty:** advanced | **Est. build time:** 8-16 hours

---

## Overview

MEMS Accelerometer Calibrator built as a Statistical analyzer. MEMS accelerometers carry bias, scale-factor, and cross-axis errors that drift with temperature, and a six-position tumble test solves for the calibration matrix that removes them. Draws a seeded synthetic sample and reports count, mean, median, stdev, quartiles, and an ASCII histogram.

**Core concept — MEMS Accelerometer Calibrator:** MEMS accelerometers carry bias, scale-factor, and cross-axis errors that drift with temperature, and a six-position tumble test solves for the calibration matrix that removes them.

**Why this matters in the real world:** Used in IMU production and drone assembly to calibrate low-cost sensors before flight.

---

## Features

- `generate_sample` (`generate_sample(seed, n)`): Draw synthetic topic measurements (mixture model).
- `percentile` (`percentile(sorted_vals, q)`): Linear-interpolation percentile of a pre-sorted list.
- `summarize` (`summarize(values, bins)`): Compute a full descriptive-statistics summary.
- `print_report` (`print_report(summary)`): Print the summary table and ASCII histogram.
- `main` (`main()`): Parse args and print the report.

## How It Works

The project is built around Descriptive statistics with linear-interpolation percentiles. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n log n) for the sort; O(n) for the histogram pass.
