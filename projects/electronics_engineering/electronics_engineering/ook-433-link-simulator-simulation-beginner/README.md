# 433 MHz OOK Link Simulator: Simulation (Logistic Growth)

**Domain:** electronics_engineering | **Subdomain:** electronics_engineering | **Difficulty:** beginner | **Est. build time:** 2-4 hours

---

## Overview

433 MHz OOK Link Simulator built as a Simulation (logistic growth). Cheap 433 MHz links send on-off keying: carrier present means 1, absent means 0, usually with simple packet framing and checksums. The simulator encodes packets, adds noise and interference, and shows the bit error rate versus signal strength. Euler-integrates logistic growth dP/dt = r*P*(1-P/K) and prints the trajectory table with summary statistics.

**Core concept — 433 MHz OOK Link Simulator:** Cheap 433 MHz links send on-off keying: carrier present means 1, absent means 0, usually with simple packet framing and checksums. The simulator encodes packets, adds noise and interference, and shows the bit error rate versus signal strength.

**Why this matters in the real world:** Garage remotes, weather stations, and cheap sensor nodes use 433 MHz OOK links.

---

## Features

- `simulate` (`simulate(params, steps, dt)`): Euler-integrate logistic growth; return [(t, value)] rows.
- `print_trajectory` (`print_trajectory(rows, every)`): Print every Nth trajectory row plus the final state.
- `main` (`main()`): Parse args, simulate, and print the trajectory and summary.
