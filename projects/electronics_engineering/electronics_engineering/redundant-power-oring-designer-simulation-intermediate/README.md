# Redundant Power OR-ing Designer: Simulation (Logistic Growth)

**Domain:** electronics_engineering | **Subdomain:** electronics_engineering | **Difficulty:** intermediate | **Est. build time:** 4-8 hours

---

## Overview

Redundant Power OR-ing Designer built as a Simulation (logistic growth). Diode OR-ing joins redundant supplies so the higher one feeds the load, but ideal-diode controllers with MOSFETs cut the diode drop and its heat. The designer checks switchover behavior and reverse-current blocking during supply faults. Euler-integrates logistic growth dP/dt = r*P*(1-P/K) and prints the trajectory table with summary statistics.

**Core concept — Redundant Power OR-ing Designer:** Diode OR-ing joins redundant supplies so the higher one feeds the load, but ideal-diode controllers with MOSFETs cut the diode drop and its heat. The designer checks switchover behavior and reverse-current blocking during supply faults.

**Why this matters in the real world:** Data centers and medical devices use OR-ed redundant supplies for uninterrupted operation.

---

## Features

- `simulate` (`simulate(params, steps, dt)`): Euler-integrate logistic growth; return [(t, value)] rows.
- `print_trajectory` (`print_trajectory(rows, every)`): Print every Nth trajectory row plus the final state.
- `main` (`main()`): Parse args, simulate, and print the trajectory and summary.
