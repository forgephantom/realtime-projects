# TRIAC Dimmer Simulator: Simulation (Logistic Growth)

**Domain:** electronics_engineering | **Subdomain:** electronics_engineering | **Difficulty:** beginner | **Est. build time:** 2-4 hours

---

## Overview

TRIAC Dimmer Simulator built as a Simulation (logistic growth). A TRIAC dimmer chops each AC half-cycle, turning on at a delayed firing angle so only part of the sine wave reaches the lamp. Later firing angles mean dimmer light but also more harmonic distortion and potential LED flicker. Euler-integrates logistic growth dP/dt = r*P*(1-P/K) and prints the trajectory table with summary statistics.

**Core concept — TRIAC Dimmer Simulator:** A TRIAC dimmer chops each AC half-cycle, turning on at a delayed firing angle so only part of the sine wave reaches the lamp. Later firing angles mean dimmer light but also more harmonic distortion and potential LED flicker.

**Why this matters in the real world:** Phase-cut dimmers in homes and theaters control incandescent and dimmable LED loads this way.

---

## Features

- `simulate` (`simulate(params, steps, dt)`): Euler-integrate logistic growth; return [(t, value)] rows.
- `print_trajectory` (`print_trajectory(rows, every)`): Print every Nth trajectory row plus the final state.
- `main` (`main()`): Parse args, simulate, and print the trajectory and summary.
