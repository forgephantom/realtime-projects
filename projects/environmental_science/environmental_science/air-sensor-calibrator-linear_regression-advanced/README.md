# Air Sensor Calibrator: Linear Regression

**Domain:** environmental_science | **Subdomain:** environmental_science | **Difficulty:** advanced | **Est. build time:** 8-16 hours

---

## Overview

Air Sensor Calibrator built as a Linear regression. Low-cost air sensors drift, so collocation against a reference monitor lets a calibration regression correct their readings. The calibrator fits the correction model and reports the sensor's accuracy after adjustment. Fits y = slope*x + intercept by closed-form least squares on seeded synthetic data and reports coefficients, R^2, and predictions.

**Core concept — Air Sensor Calibrator:** Low-cost air sensors drift, so collocation against a reference monitor lets a calibration regression correct their readings. The calibrator fits the correction model and reports the sensor's accuracy after adjustment.

**Why this matters in the real world:** Community networks calibrate low-cost sensors against regulatory monitors.

---

## Features

- `generate_data` (`generate_data(seed, n, slope, intercept, noise)`): Generate noisy (x, y) pairs around the true line.
- `fit_least_squares` (`fit_least_squares(xs, ys)`): Closed-form least-squares fit; returns (slope, intercept).
- `r_squared` (`r_squared(xs, ys, slope, intercept)`): Coefficient of determination for the fitted line.
- `main` (`main()`): Parse args, fit, and print coefficients and predictions.

## How It Works

The project is built around Ordinary least squares, closed-form normal equations. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n) to fit n points. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.
