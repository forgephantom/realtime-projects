# Coral Bleaching Risk Model: Monitoring Agent

**Domain:** environmental_science | **Subdomain:** environmental_science | **Difficulty:** beginner | **Est. build time:** 2-4 hours

---

## Overview

Coral Bleaching Risk Model built as a Monitoring agent. Corals bleach when sea temperatures exceed their summer maximum by about one degree for several weeks, tracked as degree heating weeks. The model converts temperature forecasts into bleaching risk categories for reef sites. Samples synthetic topic metrics for N cycles, evaluates each reading against thresholds, prints readings and alerts.

**Core concept — Coral Bleaching Risk Model:** Corals bleach when sea temperatures exceed their summer maximum by about one degree for several weeks, tracked as degree heating weeks. The model converts temperature forecasts into bleaching risk categories for reef sites.

**Why this matters in the real world:** Reef managers issue bleaching alerts from degree-heating-week forecasts.

---

## Features

- **Monitor**: Samples metrics, evaluates thresholds, and collects alerts.
- `read_metrics` (`read_metrics(rng, cycle)`): Sample one synthetic topic metric reading.
- `check_thresholds` (`check_thresholds(reading, thresholds)`): Return a list of alert strings for readings over threshold.
- `Monitor.run` (`Monitor.run(self, cycles, interval)`): Sample `cycles` readings, print them, return alert count.
- `main` (`main()`): Parse args and run the monitor.

## How It Works

The project is built around Periodic sampling with static threshold evaluation. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(cycles) total; O(1) per sample. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.
