# Heat Index Danger Calculator: Monitoring Agent

**Domain:** environmental_science | **Subdomain:** environmental_science | **Difficulty:** advanced | **Est. build time:** 8-16 hours

---

## Overview

Heat Index Danger Calculator built as a Monitoring agent. Heat index combines temperature and humidity into what the air actually feels like, with danger thresholds where outdoor work must stop. The calculator maps forecast conditions into caution, danger, and extreme-danger bands. Samples synthetic topic metrics for N cycles, evaluates each reading against thresholds, prints readings and alerts.

**Core concept — Heat Index Danger Calculator:** Heat index combines temperature and humidity into what the air actually feels like, with danger thresholds where outdoor work must stop. The calculator maps forecast conditions into caution, danger, and extreme-danger bands.

**Why this matters in the real world:** OSHA and sports leagues set work and play rules from heat index bands.

---

## Features

- **Monitor**: Samples metrics, evaluates thresholds, and collects alerts.
- `read_metrics` (`read_metrics(rng, cycle)`): Sample one synthetic topic metric reading.
- `check_thresholds` (`check_thresholds(reading, thresholds)`): Return a list of alert strings for readings over threshold.
- `Monitor.run` (`Monitor.run(self, cycles, interval)`): Sample `cycles` readings, print them, return alert count.
- `main` (`main()`): Parse args and run the monitor.

## How It Works

The project is built around Periodic sampling with static threshold evaluation. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(cycles) total; O(1) per sample. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.
