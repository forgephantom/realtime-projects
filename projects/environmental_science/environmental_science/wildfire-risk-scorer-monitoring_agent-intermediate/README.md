# Wildfire Risk Scorer: Monitoring Agent

**Domain:** environmental_science | **Subdomain:** environmental_science | **Difficulty:** intermediate | **Est. build time:** 4-8 hours

---

## Overview

Wildfire Risk Scorer built as a Monitoring agent. Wildfire risk blends fuel dryness, wind, ignition history, and terrain into a score that prioritizes prevention work. The scorer rates landscape cells so crews thin fuels and stage equipment where risk runs highest. Samples synthetic topic metrics for N cycles, evaluates each reading against thresholds, prints readings and alerts.

**Core concept — Wildfire Risk Scorer:** Wildfire risk blends fuel dryness, wind, ignition history, and terrain into a score that prioritizes prevention work. The scorer rates landscape cells so crews thin fuels and stage equipment where risk runs highest.

**Why this matters in the real world:** Fire agencies pre-position crews using daily risk maps.

---

## Features

- **Monitor**: Samples metrics, evaluates thresholds, and collects alerts.
- `read_metrics` (`read_metrics(rng, cycle)`): Sample one synthetic topic metric reading.
- `check_thresholds` (`check_thresholds(reading, thresholds)`): Return a list of alert strings for readings over threshold.
- `Monitor.run` (`Monitor.run(self, cycles, interval)`): Sample `cycles` readings, print them, return alert count.
- `main` (`main()`): Parse args and run the monitor.

## How It Works

The project is built around Periodic sampling with static threshold evaluation. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(cycles) total; O(1) per sample. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.
