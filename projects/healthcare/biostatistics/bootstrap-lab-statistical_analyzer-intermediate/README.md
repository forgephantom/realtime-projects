# Bootstrap Resampling Lab: Statistical Analyzer

**Domain:** healthcare | **Subdomain:** biostatistics | **Difficulty:** intermediate | **Est. build time:** 4-8 hours

---

## Overview

Bootstrap Resampling Lab built as a Statistical analyzer. A resampling teacher that estimates the sampling distribution of a statistic by bootstrapping a synthetic dataset thousands of times, building percentile confidence intervals. It compares bootstrap intervals against the theoretical ones. The method is implemented from scratch. Draws a seeded synthetic sample and reports count, mean, median, stdev, quartiles, and an ASCII histogram.

**Core concept — Bootstrap Resampling Lab:** A resampling teacher that estimates the sampling distribution of a statistic by bootstrapping a synthetic dataset thousands of times, building percentile confidence intervals. It compares bootstrap intervals against the theoretical ones. The method is implemented from scratch.

**Why this matters in the real world:** Used in statistics education to teach resampling inference.

---

## Features

- `generate_sample` (`generate_sample(seed, n)`): Draw synthetic topic measurements (mixture model).
- `percentile` (`percentile(sorted_vals, q)`): Linear-interpolation percentile of a pre-sorted list.
- `summarize` (`summarize(values, bins)`): Compute a full descriptive-statistics summary.
- `print_report` (`print_report(summary)`): Print the summary table and ASCII histogram.
- `main` (`main()`): Parse args and print the report.

## How It Works

The project is built around Descriptive statistics with linear-interpolation percentiles. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n log n) for the sort; O(n) for the histogram pass. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.
