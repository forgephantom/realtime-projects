# Midnight Census Reporter: Command-Line Tool

**Domain:** healthcare | **Subdomain:** health_informatics | **Difficulty:** beginner | **Est. build time:** 2-4 hours

---

## Overview

Midnight Census Reporter built as a Command-line tool. A daily census compiler that snapshots admissions, discharges, transfers, and deaths from synthetic ADT events into a midnight census per unit. It reconciles the census against bed capacity and produces the standard morning report with occupancy percentages. Variance flags catch units over capacity. A subcommand CLI that generates seeded synthetic topic rows and reports summaries, top-N rows, or filtered rows as tables or JSON.

**Core concept — Midnight Census Reporter:** A daily census compiler that snapshots admissions, discharges, transfers, and deaths from synthetic ADT events into a midnight census per unit. It reconciles the census against bed capacity and produces the standard morning report with occupancy percentages. Variance flags catch units over capacity.

**Why this matters in the real world:** Used by hospital administration for the daily operational census report.

---

## Features

- `generate_rows` (`generate_rows(seed, count)`): Generate deterministic synthetic topic rows.
- `cmd_summary` (`cmd_summary(rows, args)`): Print per-category counts and value statistics.
- `cmd_top` (`cmd_top(rows, args)`): Print the top-N rows by value.
- `cmd_filter` (`cmd_filter(rows, args)`): Print rows whose value is at least --min-value.
- `main` (`main()`): Parse args and dispatch to the chosen subcommand.

## How It Works

The project is built around Deterministic synthetic rows + subcommand dispatch. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n) to generate rows; O(n log n) for top-N sort. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.

## How to Run

```
cd projects/healthcare/health_informatics/census-reporter-cli_tool-beginner
python3 src/main.py --help
python3 src/main.py
```
Try `python3 src/main.py top --top-n 3`, `python3 src/main.py filter --min-value 900`, or add --json to any command.

All flags are documented in the CLI itself — run with `--help` to see every option with its default value and meaning.
