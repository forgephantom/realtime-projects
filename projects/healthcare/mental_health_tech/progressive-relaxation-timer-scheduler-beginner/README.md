# Progressive Relaxation Timer: Task Scheduler

**Domain:** healthcare | **Subdomain:** mental_health_tech | **Difficulty:** beginner | **Est. build time:** 2-4 hours

---

## Overview

Progressive Relaxation Timer built as a Task scheduler. Progressive muscle relaxation guides tensing and releasing muscle groups in sequence, with timed holds and rests per group. Session scripts order groups from feet upward and track completion. Synthetic scripts with known timings verify the timer engine. Registers interval jobs on a heap scheduler, runs them for a fixed demo duration, and prints the execution log.

**Core concept — Progressive Relaxation Timer:** Progressive muscle relaxation guides tensing and releasing muscle groups in sequence, with timed holds and rests per group. **Why this matters in the real world:** Progressive relaxation is a standard tension-reduction technique.

---

## Features

- **Scheduler**: Minimal interval scheduler driven by a heap of next-run times.
- `make_demo_job` (`make_demo_job(tag)`): Build a demo job function that counts its own executions.
- `Scheduler.add_job` (`Scheduler.add_job(self, name, interval, func)`): Register `func` to run every `interval` seconds under `name`.
- `Scheduler.run` (`Scheduler.run(self, duration)`): Run scheduled jobs for `duration` seconds; return the log.
- `main` (`main()`): Parse args, register demo jobs, run, and print the log.

## How It Works

The project is built around Heap-ordered next-run-time scheduling loop. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(log j) per execution for j jobs. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.
