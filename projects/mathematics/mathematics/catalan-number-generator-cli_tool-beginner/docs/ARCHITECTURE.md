# Architecture (HLD) — Catalan Number Generator: Command-Line Tool

## Problem & Users

Catalan Number Generator built as a Command-line tool. Catalan numbers count Dyck paths, valid parenthesis strings, binary trees, and triangulations, all growing like 4^n over n^(3/2). The generator uses the closed form C(2n,n)/(n+1) and can enumerate the actual parenthesis strings for small n. It demonstrates how one sequence governs many structures. A subcommand CLI that generates seeded synthetic topic rows and reports summaries, top-N rows, or filtered rows as tables or JSON.

The intended user is a student or engineer working in mathematics (mathematics) who needs a working, runnable reference for Catalan Number Generator — something they can read end to end, run in seconds, and adapt to their own data or experiments.

## Data Flow

```
--seed -> generate_rows (synthetic table)
subcommand: summary | top | filter -> formatted table or JSON
```

## Storage

No persistence: rows are regenerated from the seed on every invocation and nothing is written to disk.

## Scaling & Limits

Rows live in a Python list, so memory grows linearly with --rows; fine for tens of thousands of rows on a laptop.

## Trade-offs

Synthetic seeded data keeps the tool self-contained and reproducible, at the cost of not reading real input files.

## Failure Handling

An empty filter result prints a zero-count table rather than erroring; --top-n larger than the row count simply returns all rows.
