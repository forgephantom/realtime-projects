# Collatz Sequence Explorer: Web Dashboard

**Domain:** mathematics | **Subdomain:** mathematics | **Difficulty:** advanced | **Est. build time:** 8-16 hours

---

## Overview

Collatz Sequence Explorer built as a Web dashboard. The Collatz map halves even numbers and sends odd n to 3n+1; the unproven conjecture says every starting value reaches 1. Despite its simplicity the stopping times vary wildly and unpredictably. The explorer computes total stopping time and peak value for ranges of starting numbers. Serves a single-page HTML dashboard of topic metrics plus a JSON metrics endpoint.

**Core concept — Collatz Sequence Explorer:** The Collatz map halves even numbers and sends odd n to 3n+1; the unproven conjecture says every starting value reaches 1. Despite its simplicity the stopping times vary wildly and unpredictably. The explorer computes total stopping time and peak value for ranges of starting numbers.

**Why this matters in the real world:** Collatz-style iteration is a classic benchmark for arbitrary-precision arithmetic and a favorite open problem in recreational mathematics.

---

## Features

- **DashboardHandler**: Serves the dashboard HTML page and a JSON metrics endpoint.
- `metric_rows` (`metric_rows(seed, count)`): Generate deterministic synthetic metric rows.
- `render_page` (`render_page(seed, count)`): Render the full dashboard HTML page.
- `start_server` (`start_server(port, seed, count)`): Bind a ThreadingHTTPServer on 127.0.0.1 and serve it in a thread.
- `run_self_test` (`run_self_test(base_url, seed, count)`): Fetch the page and metrics endpoint; print a verification summary.
- `main` (`main()`): Parse args; self-test by default or serve with --serve.

## How It Works

The project is built around Server-side HTML rendering of a metrics table. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n) to render n metric rows. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.

## How to Run

