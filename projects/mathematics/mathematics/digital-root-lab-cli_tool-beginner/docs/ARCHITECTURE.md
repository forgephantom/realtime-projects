# Architecture (HLD) — Digital Root and Casting-Out-Nines Lab: Command-Line Tool

## Problem & Users

Digital Root and Casting-Out-Nines Lab built as a Command-line tool. The digital root is the repeated digit sum of a number, equal to the number mod 9 (with 9 in place of 0), because 10 is congruent to 1 mod 9. Casting out nines uses this to check arithmetic: the root of a sum or product must match the combination of the roots. The lab verifies long additions and multiplications this way. A subcommand CLI that generates seeded synthetic topic rows and reports summaries, top-N rows, or filtered rows as tables or JSON.

The intended user is a student or engineer working in mathematics (mathematics) who needs a working, runnable reference for Digital Root and Casting-Out-Nines Lab — something they can read end to end, run in seconds, and adapt to their own data or experiments.

Each component maps to a real module in the project; no box in this design is aspirational — everything named here exists in the source tree.

## Data Flow

```
--seed -> generate_rows (synthetic table)
subcommand: summary | top | filter -> formatted table or JSON
```

## Storage

No persistence: rows are regenerated from the seed on every invocation and nothing is written to disk.

## Scaling & Limits

Rows live in a Python list, so memory grows linearly with --rows; fine for tens of thousands of rows on a laptop.

## Trade-offs

Synthetic seeded data keeps the tool self-contained and reproducible, at the cost of not reading real input files.

## Failure Handling

An empty filter result prints a zero-count table rather than erroring; --top-n larger than the row count simply returns all rows.
