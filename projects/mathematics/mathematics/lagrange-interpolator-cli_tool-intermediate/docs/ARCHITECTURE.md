# Architecture (HLD) — Lagrange Interpolator: Command-Line Tool

## Problem & Users

Lagrange Interpolator built as a Command-line tool. Lagrange interpolation builds the unique degree n-1 polynomial through n points as a weighted sum of basis polynomials, each equal to 1 at its own node and 0 at the others. It is exact on the nodes but can oscillate wildly between them (Runge's phenomenon). The tool evaluates the interpolant and its node errors. A subcommand CLI that generates seeded synthetic topic rows and reports summaries, top-N rows, or filtered rows as tables or JSON.

The intended user is a student or engineer working in mathematics (mathematics) who needs a working, runnable reference for Lagrange Interpolator — something they can read end to end, run in seconds, and adapt to their own data or experiments.

Each component maps to a real module in the project; no box in this design is aspirational — everything named here exists in the source tree.

## Data Flow

```
--seed -> generate_rows (synthetic table)
subcommand: summary | top | filter -> formatted table or JSON
```

## Storage

No persistence: rows are regenerated from the seed on every invocation and nothing is written to disk.

## Scaling & Limits

Rows live in a Python list, so memory grows linearly with --rows; fine for tens of thousands of rows on a laptop.

## Trade-offs

Synthetic seeded data keeps the tool self-contained and reproducible, at the cost of not reading real input files.

## Failure Handling

An empty filter result prints a zero-count table rather than erroring; --top-n larger than the row count simply returns all rows.
