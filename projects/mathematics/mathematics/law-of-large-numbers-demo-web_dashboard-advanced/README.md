# Law of Large Numbers Demonstrator: Web Dashboard

**Domain:** mathematics | **Subdomain:** mathematics | **Difficulty:** advanced | **Est. build time:** 8-16 hours

---

## Overview

Law of Large Numbers Demonstrator built as a Web dashboard. The law of large numbers guarantees sample averages converge to the expected value as the sample grows, the mathematical backbone of all simulation. Watching the running average of coin flips or die rolls settle is the most direct demonstration. The tool plots the running mean with shrinking error bands. Serves a single-page HTML dashboard of topic metrics plus a JSON metrics endpoint.

**Core concept — Law of Large Numbers Demonstrator:** The law of large numbers guarantees sample averages converge to the expected value as the sample grows, the mathematical backbone of all simulation. Watching the running average of coin flips or die rolls settle is the most direct demonstration. The tool plots the running mean with shrinking error bands.

**Why this matters in the real world:** The law justifies polling, Monte Carlo methods, and quality-control sampling plans.

---

## Features

- **DashboardHandler**: Serves the dashboard HTML page and a JSON metrics endpoint.
- `metric_rows` (`metric_rows(seed, count)`): Generate deterministic synthetic metric rows.
- `render_page` (`render_page(seed, count)`): Render the full dashboard HTML page.
- `start_server` (`start_server(port, seed, count)`): Bind a ThreadingHTTPServer on 127.0.0.1 and serve it in a thread.
- `run_self_test` (`run_self_test(base_url, seed, count)`): Fetch the page and metrics endpoint; print a verification summary.
- `main` (`main()`): Parse args; self-test by default or serve with --serve.

## How It Works

The project is built around Server-side HTML rendering of a metrics table. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n) to render n metric rows. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.

## How to Run

```

python3 src/main.py
```

All flags are documented in the CLI itself — run with `--help` to see every option with its default value and meaning.
