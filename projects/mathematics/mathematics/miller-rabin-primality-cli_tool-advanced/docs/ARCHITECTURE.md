# Architecture (HLD) — Miller-Rabin Probabilistic Primality Tester: Command-Line Tool

## Problem & Users

Miller-Rabin Probabilistic Primality Tester built as a Command-line tool. The Miller-Rabin test decides primality by checking whether a number behaves like a prime under several random bases, using Fermat-style witnesses on the odd part of n minus 1. Each round halves the chance of a false positive, so a handful of rounds gives near-certainty. It is the workhorse test behind real key generation. A subcommand CLI that generates seeded synthetic topic rows and reports summaries, top-N rows, or filtered rows as tables or JSON.

The intended user is a student or engineer working in mathematics (mathematics) who needs a working, runnable reference for Miller-Rabin Probabilistic Primality Tester — something they can read end to end, run in seconds, and adapt to their own data or experiments.

## Data Flow

```
--seed -> generate_rows (synthetic table)
subcommand: summary | top | filter -> formatted table or JSON
```

## Storage

No persistence: rows are regenerated from the seed on every invocation and nothing is written to disk.

## Scaling & Limits

Rows live in a Python list, so memory grows linearly with --rows; fine for tens of thousands of rows on a laptop.

## Trade-offs

Synthetic seeded data keeps the tool self-contained and reproducible, at the cost of not reading real input files.

## Failure Handling

An empty filter result prints a zero-count table rather than erroring; --top-n larger than the row count simply returns all rows.
