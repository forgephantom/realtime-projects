# Architecture (HLD) — Polygon Area Calculator (Shoelace): Command-Line Tool

## Problem & Users

Polygon Area Calculator (Shoelace) built as a Command-line tool. The shoelace formula computes polygon area by summing cross products of consecutive vertices, with the sign indicating winding orientation. It handles concave polygons as long as vertices are ordered without self-intersection. The calculator validates the vertex order and reports area and centroid. A subcommand CLI that generates seeded synthetic topic rows and reports summaries, top-N rows, or filtered rows as tables or JSON.

The intended user is a student or engineer working in mathematics (mathematics) who needs a working, runnable reference for Polygon Area Calculator (Shoelace) — something they can read end to end, run in seconds, and adapt to their own data or experiments.

## Data Flow

```
--seed -> generate_rows (synthetic table)
subcommand: summary | top | filter -> formatted table or JSON
```

## Storage

No persistence: rows are regenerated from the seed on every invocation and nothing is written to disk.

## Scaling & Limits

Rows live in a Python list, so memory grows linearly with --rows; fine for tens of thousands of rows on a laptop.

## Trade-offs

Synthetic seeded data keeps the tool self-contained and reproducible, at the cost of not reading real input files.

## Failure Handling

An empty filter result prints a zero-count table rather than erroring; --top-n larger than the row count simply returns all rows.
