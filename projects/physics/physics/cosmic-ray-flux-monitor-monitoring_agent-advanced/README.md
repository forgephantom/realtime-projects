# Cosmic Ray Flux Monitor: Monitoring Agent

**Domain:** physics | **Subdomain:** physics | **Difficulty:** advanced | **Est. build time:** 8-16 hours

---

## Overview

Cosmic Ray Flux Monitor built as a Monitoring agent. Cosmic rays rain down constantly, and their flux rises and falls with the solar cycle as the solar wind shields Earth. The monitor counts synthetic detector hits, corrects for pressure and temperature, and tracks the flux trend. Samples synthetic topic metrics for N cycles, evaluates each reading against thresholds, prints readings and alerts.

**Core concept — Cosmic Ray Flux Monitor:** Cosmic rays rain down constantly, and their flux rises and falls with the solar cycle as the solar wind shields Earth. The monitor counts synthetic detector hits, corrects for pressure and temperature, and tracks the flux trend.

**Why this matters in the real world:** Neutron monitor stations worldwide track cosmic ray flux for space weather forecasting.

---

## Features

- **Monitor**: Samples metrics, evaluates thresholds, and collects alerts.
- `read_metrics` (`read_metrics(rng, cycle)`): Sample one synthetic topic metric reading.
- `check_thresholds` (`check_thresholds(reading, thresholds)`): Return a list of alert strings for readings over threshold.
- `Monitor.run` (`Monitor.run(self, cycles, interval)`): Sample `cycles` readings, print them, return alert count.
- `main` (`main()`): Parse args and run the monitor.

## How It Works

The project is built around Periodic sampling with static threshold evaluation. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(cycles) total; O(1) per sample. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.
