# Half Life Data Fitter: Linear Regression

**Domain:** physics | **Subdomain:** physics | **Difficulty:** beginner | **Est. build time:** 2-4 hours

---

## Overview

Half Life Data Fitter built as a Linear regression. Taking the logarithm of activity measurements turns an exponential decay curve into a straight line whose slope gives the decay constant. The fitter handles background counts and dead-time corrections before extracting the half-life. Fits y = slope*x + intercept by closed-form least squares on seeded synthetic data and reports coefficients, R^2, and predictions.

**Core concept — Half Life Data Fitter:** Taking the logarithm of activity measurements turns an exponential decay curve into a straight line whose slope gives the decay constant. The fitter handles background counts and dead-time corrections before extracting the half-life.

**Why this matters in the real world:** Environmental labs date groundwater and check contamination from isotope activity measurements.

---

## Features

- `generate_data` (`generate_data(seed, n, slope, intercept, noise)`): Generate noisy (x, y) pairs around the true line.
- `fit_least_squares` (`fit_least_squares(xs, ys)`): Closed-form least-squares fit; returns (slope, intercept).
- `r_squared` (`r_squared(xs, ys, slope, intercept)`): Coefficient of determination for the fitted line.
- `main` (`main()`): Parse args, fit, and print coefficients and predictions.

## How It Works

The project is built around Ordinary least squares, closed-form normal equations. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n) to fit n points. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.
