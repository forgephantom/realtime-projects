# Piezoelectric Sensor Model: Command-Line Tool

**Domain:** physics | **Subdomain:** physics | **Difficulty:** advanced | **Est. build time:** 8-16 hours

---

## Overview

Piezoelectric Sensor Model built as a Command-line tool. Squeezing a piezoelectric crystal generates a voltage proportional to the applied force, and the effect reverses to make actuators. The model converts mechanical stress into charge output through the piezoelectric coefficient. A subcommand CLI that generates seeded synthetic topic rows and reports summaries, top-N rows, or filtered rows as tables or JSON.

**Core concept — Piezoelectric Sensor Model:** Squeezing a piezoelectric crystal generates a voltage proportional to the applied force, and the effect reverses to make actuators. The model converts mechanical stress into charge output through the piezoelectric coefficient.

**Why this matters in the real world:** Engine knock sensors and guitar pickups convert vibration to voltage with piezoelectric elements.

---

## Features

- `generate_rows` (`generate_rows(seed, count)`): Generate deterministic synthetic topic rows.
- `cmd_summary` (`cmd_summary(rows, args)`): Print per-category counts and value statistics.
- `cmd_top` (`cmd_top(rows, args)`): Print the top-N rows by value.
- `cmd_filter` (`cmd_filter(rows, args)`): Print rows whose value is at least --min-value.
- `main` (`main()`): Parse args and dispatch to the chosen subcommand.

## How It Works

The project is built around Deterministic synthetic rows + subcommand dispatch. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n) to generate rows; O(n log n) for top-N sort. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.

## How to Run

```
cd projects/physics/physics/piezoelectric-sensor-model-cli_tool-advanced
python3 src/main.py --help
python3 src/main.py
```
Try `python3 src/main.py top --top-n 3`, `python3 src/main.py filter --min-value 900`, or add --json to any command.

All flags are documented in the CLI itself — run with `--help` to see every option with its default value and meaning.
