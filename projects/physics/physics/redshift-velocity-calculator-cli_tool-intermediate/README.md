# Redshift Velocity Calculator: Command-Line Tool

**Domain:** physics | **Subdomain:** physics | **Difficulty:** intermediate | **Est. build time:** 4-8 hours

---

## Overview

Redshift Velocity Calculator built as a Command-line tool. The redshift of a galaxy's spectral lines measures how fast it recedes, since the expansion of space stretches the light in transit. For nearby galaxies the velocity is simply the redshift times the speed of light; distant ones need the full cosmological model. A subcommand CLI that generates seeded synthetic topic rows and reports summaries, top-N rows, or filtered rows as tables or JSON.

**Core concept — Redshift Velocity Calculator:** The redshift of a galaxy's spectral lines measures how fast it recedes, since the expansion of space stretches the light in transit. For nearby galaxies the velocity is simply the redshift times the speed of light; distant ones need the full cosmological model.

**Why this matters in the real world:** Galaxy survey teams map large-scale structure from redshift-derived distances.

---

## Features

- `generate_rows` (`generate_rows(seed, count)`): Generate deterministic synthetic topic rows.
- `cmd_summary` (`cmd_summary(rows, args)`): Print per-category counts and value statistics.
- `cmd_top` (`cmd_top(rows, args)`): Print the top-N rows by value.
- `cmd_filter` (`cmd_filter(rows, args)`): Print rows whose value is at least --min-value.
- `main` (`main()`): Parse args and dispatch to the chosen subcommand.

## How It Works

The project is built around Deterministic synthetic rows + subcommand dispatch. Input data flows from src/main.py through the processing modules, and the overall approach runs in O(n) to generate rows; O(n log n) for top-N sort. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the high-level design and [docs/DESIGN.md](docs/DESIGN.md) for the detailed module breakdown.

## How to Run

```
cd projects/physics/physics/redshift-velocity-calculator-cli_tool-intermediate
python3 src/main.py --help
python3 src/main.py
```
Try `python3 src/main.py top --top-n 3`, `python3 src/main.py filter --min-value 900`, or add --json to any command.

All flags are documented in the CLI itself — run with `--help` to see every option with its default value and meaning.
